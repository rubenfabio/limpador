# T-00.01 — Esqueleto do projeto e testes unitários

**Feature:** F00 · **Fase:** MVP · **Depende de:** —

## Regras de negócio

- O projeto tem três partes separadas: **núcleo** (biblioteca, independente da interface), **app desktop** (casca que liga núcleo e interface) e **interface**.
- Cada parte tem um teste unitário de exemplo passando.
- Um único comando roda todos os unitários do projeto e devolve um código de erro se algum falhar.
- O núcleo compila e testa **sem** a interface, para que a Fase 2 o reutilize na CLI e no MCP.
- Formatação e lint configurados nas duas linguagens, com um comando de verificação.

## Critérios de aceite

- [x] **CA1** Dado o projeto recém-clonado, quando o comando de testes unitários roda, então os testes de exemplo do núcleo e da interface passam.
- [x] **CA2** Dado um teste de exemplo alterado para falhar, quando o comando roda, então ele termina com código de erro.
- [x] **CA3** Dado o núcleo isolado, quando compilado e testado sozinho, então funciona sem nenhuma dependência da interface.
- [x] **CA4** Dado um arquivo fora do padrão de formatação, quando a verificação roda, então ela falha apontando o arquivo.
