# T-00.02 — Máquina falsa (gerador de cenários e dublês)

**Feature:** F00 · **Fase:** MVP · **Depende de:** T-00.01

## Contexto

É a base dos testes de integração e do e2e do app real. Precisa ser realista o bastante para provar as regras de segurança sem nunca tocar a máquina real.

## Regras de negócio

**Gerador de cenários**
- Monta numa pasta temporária: pastas raiz, projetos de vários ecossistemas, caches globais, Downloads, Temp, locais de ferramentas de IA, todos com **datas controladas** (para simular projeto parado há N dias).
- Cria repositórios git **reais**: merge normal, squash, rebase, branches abandonadas, upstream apagado, worktrees (limpa, suja, travada, órfã), stashes, e um remoto local que faz o papel do GitHub.
- Monta casos do Windows: caminho com mais de 260 caracteres, junção apontando para fora, arquivo travado em uso, nomes com espaço e acento.
- Cenários são descritos de forma declarativa e reutilizável (ex.: "projeto Node parado há 45 dias com pnpm").
- Tudo é apagado ao fim do teste, mesmo se o teste falhar.

**Dublês**
- Docker e WSL simulados: respondem como os comandos reais a partir de um estado configurado (imagens, containers, volumes, discos) e **registram** cada comando recebido, para o teste verificar o que foi pedido.
- API do GitHub simulada: PRs mergeados, fechados e abertos, limite de requisições, ausência de autenticação.
- Relógio controlado.

**Sandbox**
- O núcleo e o app aceitam uma configuração de sandbox (catálogo, pastas de dados, dublês) **apenas em builds de teste**.

**Crescimento incremental**
- Esta tarefa entrega o necessário para F01 e F02. Cada tarefa de coletor acrescenta os cenários de que precisa.

## Critérios de aceite

- [ ] **CA1** Dado o cenário "projeto parado há 45 dias", quando gerado, então as datas dos arquivos e do último commit correspondem a 45 dias atrás no relógio controlado.
- [ ] **CA2** Dado o cenário "branch integrada por squash", quando gerado, então o repositório real tem a branch, o commit de squash na `main` e o upstream apagado.
- [ ] **CA3** Dado um teste que falha no meio, quando termina, então a pasta temporária foi removida.
- [ ] **CA4** Dado o dublê de Docker com 3 imagens, quando o coletor pede para remover uma, então o dublê registra o comando e passa a listar 2.
- [ ] **CA5** Dado um build de produção, quando recebe a configuração de sandbox, então a ignora ou recusa iniciar com ela.
- [ ] **CA6** Dada a junção do cenário apontando para fora, quando o teste termina, então o alvo da junção continua intacto.
