# T-01.01 — Modelo de item limpável

**Feature:** F01 · **Fase:** MVP · **Depende de:** —

## Contexto

Tudo o que o app mostra e limpa é um "item limpável". Este modelo é a linguagem comum entre coletores, motor, interface, quarentena e histórico.

## Regras de negócio

Todo item tem:

| Campo | Regra |
|---|---|
| Identificador | **Estável**: o mesmo recurso gera o mesmo identificador em análises diferentes (derivado do coletor + recurso) |
| Categoria | Uma de: Docker · Dependências e builds · Git · IA e editores · Arquivos gerais |
| Coletor e tipo | Ex.: coletor Docker, tipo "volume" |
| Recurso | Caminho no disco ou identificador (nome de imagem, branch, volume) |
| Nome legível | Como aparece para o usuário |
| Tamanho aparente e tamanho liberável | Em bytes. Liberável = o que realmente volta ao disco (ex.: descontando hardlinks compartilhados). Pode ser 0 em itens de organização |
| Tamanho estimado? | Indica quando o tamanho é estimativa e não medição |
| Natureza | **Recriável** ou **Conteúdo do usuário** |
| Risco | 🟢 / 🟡 / 🔴 / ⛔ (regra em T-01.02) |
| Motivo | Texto legível com dados concretos. **Obrigatório** |
| Como recriar | **Obrigatório** se a natureza for recriável |
| Projeto associado | Opcional |
| Última atividade | Data, quando aplicável |
| Ação | Excluir · Mover para quarentena · Compactar · Comando do gerenciador |
| Efeitos colaterais | Ex.: "interrompe o Docker". Lista vazia se não houver |
| Motivo do bloqueio | Obrigatório quando ⛔ |
| Itens contidos | Itens que estão dentro deste (ex.: `node_modules` dentro de uma worktree) |
| Alertas | Avisos extras (ex.: "contém arquivo `.env`") |

- **Itens de organização**: itens com tamanho 0 (branches, stashes, redes) contam num total separado de "itens de organização", não no espaço recuperável.
- **Sem dupla contagem**: se um item contém outro, os totais contam o espaço uma única vez.

## Critérios de aceite

- [x] **CA1** Dado o mesmo recurso, quando analisado duas vezes, então recebe o mesmo identificador.
- [x] **CA2** Dado um item sem motivo, quando um coletor tenta registrá-lo, então o registro é rejeitado.
- [x] **CA3** Dado um item recriável sem "como recriar", quando registrado, então é rejeitado.
- [x] **CA4** Dado um item ⛔ sem motivo de bloqueio, quando registrado, então é rejeitado.
- [x] **CA5** Dada uma worktree de 3 GB que contém um `node_modules` de 1 GB, quando os totais são calculados com os dois itens presentes, então o total é 3 GB e não 4 GB.
- [x] **CA6** Dada uma branch (tamanho 0), quando os totais são calculados, então ela conta em "itens de organização" e não altera o espaço recuperável.
