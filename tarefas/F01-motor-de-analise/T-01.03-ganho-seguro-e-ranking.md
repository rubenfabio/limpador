# T-01.03 — Ganho seguro e ranking

**Feature:** F01 · **Fase:** MVP · **Depende de:** T-01.02, T-01.06

## Contexto

O ranking principal ordena por **ganho seguro**: no topo fica o que libera mais espaço com menos chance de causar problema.

## Regras de negócio

**Fórmula**

```
ganho seguro = tamanho liberável × peso do risco × peso da atividade
```

| Peso do risco | | Peso da atividade | |
|---|---|---|---|
| 🟢 | 1,0 | Item sem projeto | 1,0 |
| 🟡 | 0,6 | Projeto inativo | 1,0 |
| 🔴 | 0,2 | Projeto ativo (inclui fixados) | 0,3 |
| ⛔ | 0 | | |

**Ordenação**

1. Ganho seguro, decrescente.
2. Desempate: maior tamanho liberável → mais tempo sem atividade → nome (ordem alfabética).
3. Itens ⛔ ficam no fim, na ordem de tamanho.
4. Itens de organização (tamanho 0) formam uma **lista separada**, ordenada por risco (🟢 primeiro) e depois por idade.

**Totais produzidos pela análise**

- Recuperável total (tudo menos ⛔ e protegidos).
- Recuperável seguro (só 🟢).
- Por risco, por categoria e por projeto (incluindo o grupo "Sem projeto").
- Quantidade de itens de organização.

## Critérios de aceite

- [ ] **CA1** Dados A = 10 GB 🟡 de projeto inativo (6,0) e B = 8 GB 🟢 sem projeto (8,0), quando ranqueados, então B vem antes de A.
- [ ] **CA2** Dado C = 20 GB 🟡 de projeto ativo (3,6), quando ranqueado com A e B, então a ordem é B, A, C.
- [ ] **CA3** Dados dois itens com o mesmo ganho, quando ranqueados, então o maior tamanho vem primeiro.
- [ ] **CA4** Dado um item ⛔ de 50 GB, quando ranqueado, então aparece depois de todos os não bloqueados.
- [ ] **CA5** Dadas três branches mergeadas, quando o resultado é gerado, então elas aparecem na lista de organização e não no ranking de espaço.
- [ ] **CA6** Dado qualquer resultado, quando somados os totais por categoria, então o valor bate com o recuperável total.
