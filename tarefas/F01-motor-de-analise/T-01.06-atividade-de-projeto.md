# T-01.06 — Atividade de projeto e associação de itens

**Feature:** F01 · **Fase:** MVP · **Depende de:** T-01.01 (usa os projetos de T-02.03)

## Contexto

Saber se um projeto está **parado** é o que diferencia "`node_modules` que você usa todo dia" de "`node_modules` de um protótipo de 4 meses atrás".

## Regras de negócio

**Última atividade do projeto** = a mais recente entre:
- o último commit em qualquer branch local;
- a última modificação de arquivo **não ignorado** pelo git (ou, sem git, fora das pastas de dependência e build conhecidas);
- "agora", se houver container rodando associado ao projeto.

Pastas de dependência e build (`node_modules`, `.venv`, `target`, `dist`...) **não contam** como atividade, porque mudam em qualquer instalação.

**Estado**
- **Inativo**: última atividade há mais de 30 dias (limiar configurável, T-02.05).
- **Ativo**: caso contrário.
- **Fixado** pelo usuário: sempre ativo.

**Associação item → projeto**
- Por caminho: o item pertence ao projeto mais específico que o contém.
- Por rótulo: recursos Docker com rótulo de projeto do Compose são associados ao projeto daquela pasta.
- Worktrees pertencem ao projeto do repositório de origem.
- Sem correspondência: grupo "Sem projeto".

## Critérios de aceite

- [ ] **CA1** Dado um projeto com último commit há 45 dias e nenhum arquivo alterado depois, quando analisado, então está inativo há 45 dias.
- [ ] **CA2** Dado o mesmo projeto com um arquivo de código alterado ontem, quando analisado, então está ativo.
- [ ] **CA3** Dado um projeto cujo único arquivo recente está em `node_modules`, quando analisado, então continua inativo.
- [ ] **CA4** Dado um projeto inativo com container rodando associado, quando analisado, então está ativo.
- [ ] **CA5** Dado um projeto inativo fixado, quando analisado, então está ativo.
- [ ] **CA6** Dado um monorepo com `apps/web/node_modules`, quando associado, então o item pertence ao monorepo.
- [ ] **CA7** Dado um volume com rótulo do Compose apontando para `C:\Projetos\api`, quando associado, então pertence ao projeto `api`.
