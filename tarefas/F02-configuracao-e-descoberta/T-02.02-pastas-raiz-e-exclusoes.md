# T-02.02 — Pastas raiz e exclusões

**Feature:** F02 · **Fase:** MVP · **Depende de:** T-02.05

## Regras de negócio

- O usuário adiciona e remove pastas raiz a qualquer momento.
- Ao adicionar, o app valida se a pasta existe e se pode ser lida.
- **Sem sobreposição**: adicionar uma pasta que está dentro de outra raiz é desnecessário, e o app avisa; adicionar uma pasta que contém raízes existentes substitui essas raízes (com aviso).
- **Exclusões**: o usuário pode excluir caminhos ou padrões dentro das raízes (ex.: `C:\Projetos\cliente-x`, `**/vendor`). Nada dentro de uma exclusão é analisado.
- **Raiz indisponível** (ex.: disco externo desconectado): aparece como aviso no resultado, sem erro; os itens dela somem da análise até ela voltar.
- Remover uma raiz tira seus itens da próxima análise. Nada é apagado.

## Critérios de aceite

- [x] **CA1** Dada a raiz `C:\Projetos`, quando o usuário adiciona `C:\Projetos\estudo`, então o app avisa que ela já está coberta e não a duplica.
- [x] **CA2** Dadas as raízes `C:\a\x` e `C:\a\y`, quando o usuário adiciona `C:\a`, então `C:\a` substitui as duas, após aviso.
- [x] **CA3** Dada a exclusão `C:\Projetos\cliente-x`, quando a análise roda, então nenhum item daquele caminho aparece.
- [x] **CA4** Dada uma raiz num disco desconectado, quando a análise roda, então o resultado traz um aviso e a análise conclui normalmente.
- [x] **CA5** Dado um caminho inexistente, quando o usuário tenta adicioná-lo, então o app recusa com mensagem.
