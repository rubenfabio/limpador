# T-03.01 — Detecção do Docker e do WSL

**Feature:** F03 · **Fase:** MVP · **Depende de:** T-01.04

## Regras de negócio

O coletor identifica um destes estados:

| Estado | Comportamento |
|---|---|
| Docker não instalado e WSL ausente | Coletor aparece como "não instalado" |
| Docker não instalado, WSL presente | Analisa só os discos das distros WSL (T-03.06) |
| Docker instalado e **parado** | Mostra "Docker parado: inicie-o para analisar imagens, containers e volumes" e analisa os discos virtuais assim mesmo |
| Docker rodando | Análise completa |
| Outro motor (Podman, Rancher Desktop...) | "Ainda não suportado", sem erro |

- A análise **nunca** inicia o Docker nem o WSL sozinha (I1).
- O botão "Iniciar Docker" só age com clique do usuário.
- O estado detectado é revalidado antes de qualquer limpeza.

## Critérios de aceite

- [ ] **CA1** Dado o Docker Desktop instalado e parado (como na máquina do usuário hoje), quando a análise roda, então o coletor mostra "Docker parado" com a ação de iniciar e ainda lista os discos virtuais.
- [ ] **CA2** Dado o Docker rodando, quando a análise roda, então imagens, containers, volumes e cache são analisados.
- [ ] **CA3** Dado o Docker parado, quando a análise termina, então o Docker continua parado.
- [ ] **CA4** Dada uma máquina sem Docker e sem WSL, quando a análise roda, então o coletor aparece como "não instalado" e a análise conclui sem erro.
