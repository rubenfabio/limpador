# T-03.05 — Cache de build e redes

**Feature:** F03 · **Fase:** MVP · **Depende de:** T-03.01

## Regras de negócio

**Cache de build**
- Cache não usado há mais de 7 dias → 🟢, recriável ("refeito no próximo build, que pode demorar mais").
- O cache usado nos últimos 7 dias aparece no detalhe como informação, mas não é candidato.
- Um único item agregado "Cache de build do Docker", com o total liberável.

**Redes**
- Redes criadas pelo usuário ou pelo Compose sem nenhum container conectado → 🟢, item de organização (tamanho 0).
- As redes padrão do Docker (bridge, host, none) nunca são candidatas.

## Critérios de aceite

- [x] **CA1** Dados 8 GB de cache, dos quais 2 GB usados ontem, quando analisado, então o item mostra 6 GB liberáveis.
- [x] **CA2** Dada uma rede do Compose sem containers, quando analisada, então é 🟢 de organização.
- [x] **CA3** Dada a rede `bridge`, quando analisada, então não aparece.
- [x] **CA4** Dado o cache de build elegível, quando a elegibilidade para automação é calculada, então é elegível.
