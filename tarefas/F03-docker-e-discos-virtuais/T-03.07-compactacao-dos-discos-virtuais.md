# T-03.07 — Compactação dos discos virtuais

**Feature:** F03 · **Fase:** MVP · **Depende de:** T-03.06, T-09.01

## Contexto

É o que devolve ao Windows o espaço liberado dentro do Docker/WSL. Na máquina do usuário, é provavelmente a ação de maior ganho.

## Regras de negócio

**Pré-condições**
- A compactação exige que o Docker e a distro estejam parados.
- Antes de executar, o app lista **tudo o que será interrompido** (containers rodando, distros WSL abertas) e pede confirmação específica.
- **Nunca é automática**, nem por agendamento nem por agente, mesmo sendo 🟢.
- Se exigir privilégio de administrador, o app pede elevação ao sistema. Se for negada, cancela sem alterar nada.

**Execução**
1. Recomenda-se rodar primeiro a limpeza dos itens Docker selecionados.
2. Parar o Docker e as distros afetadas.
3. Compactar o disco.
4. Religar o que estava rodando antes.
5. Reportar o tamanho do arquivo antes e depois.

**Falhas**
- Se a compactação falhar no meio, o disco permanece íntegro e o app religa os serviços que estavam rodando.
- Se o método de compactação não estiver disponível nesta edição do Windows, o app usa um método alternativo ou explica claramente o que falta.

**Modo esparso (opcional)**
- O app pode oferecer ativar o encolhimento automático do disco. É uma configuração persistente do sistema: exige explicação e confirmação explícita, separada da compactação.

## Critérios de aceite

- [ ] **CA1** Dados containers rodando, quando o usuário pede a compactação, então a confirmação lista cada container que será interrompido.
- [ ] **CA2** Dada a elevação negada, quando a compactação é pedida, então nada é alterado e o resultado é "cancelado pelo usuário".
- [ ] **CA3** Dado o Docker rodando antes, quando a compactação termina, então o Docker é religado.
- [ ] **CA4** Dada uma compactação concluída, então o relatório mostra o tamanho do arquivo antes e depois e o log registra a ação.
- [ ] **CA5** Dada a limpeza automática ligada, quando ela roda, então nunca inclui compactação.
- [ ] **CA6** Dada uma falha simulada no meio, quando a compactação aborta, então o disco continua utilizável e os serviços são religados.
