# T-04.03 — Caches globais de gerenciadores JS

**Feature:** F04 · **Fase:** MVP · **Depende de:** T-01.04

## Regras de negócio

| Gerenciador | Ação | Risco |
|---|---|---|
| npm | Limpar o cache | 🟢 |
| pnpm | **Somente** remover pacotes do store não referenciados por nenhum projeto (prune). Nunca apagar o store inteiro | 🟢 |
| yarn (clássico e moderno) | Limpar o cache global | 🟢 |
| bun | Limpar o cache | 🟢 |

- Preferir o **comando oficial** do gerenciador. Se o gerenciador não estiver mais instalado mas o cache existir, remover a pasta.
- Itens sem projeto (peso de atividade 1,0), elegíveis para automação.
- Se houver um processo do gerenciador rodando (instalação em andamento), o item é ⛔.
- Tamanho do pnpm: o liberável é apenas o dos pacotes não referenciados.

## Critérios de aceite

- [ ] **CA1** Dado um cache npm de 3 GB, quando analisado, então aparece como 🟢 sem projeto.
- [ ] **CA2** Dado o store do pnpm, quando limpo, então só os pacotes não referenciados são removidos e os projetos continuam funcionando sem reinstalar.
- [ ] **CA3** Dada uma instalação npm em andamento, quando revalidado, então o item fica ⛔.
- [ ] **CA4** Dado um cache do yarn com o yarn desinstalado, quando limpo, então a pasta é removida.
