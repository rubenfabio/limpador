# T-04.06 — Versões de runtime não usadas

**Feature:** F04 · **Fase:** MVP · **Depende de:** T-02.03

## Regras de negócio

- Gerenciadores suportados: Node (nvm-windows, fnm, volta) e Python (pyenv-win).
- Uma versão está **em uso** se:
  - é a versão padrão ou ativa do gerenciador; ou
  - é pedida **exatamente** por algum projeto (`.nvmrc`, `.node-version`, fixação do volta, `.python-version`); ou
  - é a **mais nova versão instalada** que satisfaz uma faixa pedida por algum projeto (ex.: `engines.node >= 18`).
- Versão não usada → 🟡, recriável ("reinstale com `nvm install X`").
- **Nunca** é candidata a única versão instalada de um runtime.

## Critérios de aceite

- [ ] **CA1** Dadas as versões 16, 18 e 20 do Node, padrão 20, e um projeto com `.nvmrc` = 18, quando analisado, então só a 16 é candidata.
- [ ] **CA2** Dado `engines.node >= 18` com 18 e 20 instaladas e nenhuma outra regra, quando analisado, então a 20 fica e a 18 é candidata.
- [ ] **CA3** Dada uma única versão instalada, quando analisado, então ela não é candidata.
- [ ] **CA4** Dada uma versão candidata, então o item mostra o comando de reinstalação.
