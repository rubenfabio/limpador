# T-05.01 — Inventário de repositórios

**Feature:** F05 · **Fase:** MVP · **Depende de:** T-02.03

## Regras de negócio

Para cada repositório git nas pastas raiz, o app levanta:

- **Branch padrão**: a indicada pelo remoto principal; sem essa indicação, `main` ou `master` se existir. Se não for possível determinar, **nenhuma branch do repositório recebe veredito de merge**: todas ficam ⛔ com o motivo "branch padrão desconhecida".
- Remotos e o host de cada um (GitHub ou outro).
- Estado da cópia de trabalho: limpa ou com alterações pendentes (incluindo arquivos novos não ignorados).
- Data do último fetch. Se tiver mais de 7 dias, o resultado avisa "dados do remoto desatualizados".
- Lista de branches locais, upstreams, worktrees e stashes.

**Fetch**
- A análise **não** faz fetch por padrão (I1).
- O usuário pode clicar em "atualizar remotos" (fetch com remoção de referências apagadas) por repositório ou para todos.
- Existe a preferência "atualizar remotos antes de analisar" (desligada por padrão).

## Critérios de aceite

- [ ] **CA1** Dado um repositório cujo remoto aponta `main` como padrão, quando inventariado, então a branch padrão é `main`.
- [ ] **CA2** Dado um repositório sem remoto e sem `main`/`master`, quando inventariado, então todas as branches ficam ⛔ "branch padrão desconhecida".
- [ ] **CA3** Dado um repositório com último fetch há 20 dias, quando inventariado, então o resultado avisa que os dados do remoto estão desatualizados.
- [ ] **CA4** Dada a análise padrão, quando roda, então nenhuma referência do repositório muda.
