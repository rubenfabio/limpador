# T-05.02 — Detecção de merge por sinais locais

**Feature:** F05 · **Fase:** MVP · **Depende de:** T-05.01

## Contexto

Verificar só se uma branch é ancestral da padrão não pega squash merge nem rebase merge, que são os mais comuns em PRs. É preciso combinar sinais.

## Regras de negócio

**Branches excluídas da análise:** a branch atual, a branch padrão, branches protegidas e branches em uso por uma worktree (avaliadas junto com a worktree em T-05.05).

**Sinais**

| Sinal | Significado |
|---|---|
| S1 Ancestral | A ponta da branch já está contida na branch padrão (remota, ou local se não houver remoto) |
| S2 Upstream apagado | A branch tinha upstream e a referência remota não existe mais |
| S3 Conteúdo equivalente | As mudanças da branch já estão na branch padrão (commits equivalentes ou diff combinado já aplicado), o que cobre squash e rebase |
| S4 Commits únicos | Existem commits na branch que não estão em nenhuma referência remota |
| S5 Espelho do remoto | A ponta local é idêntica à ponta do upstream |

**Veredito**

| Condição | Veredito | Risco |
|---|---|---|
| S1 | Mergeada | 🟢 |
| S3 (sem S1) | Mergeada por conteúdo | 🟡 |
| S5 e branch sem commits há mais que o limiar de inatividade | Cópia de branch remota parada | 🟢 |
| S2 sem S1/S3 | Remoto apagado sem evidência de merge | 🔴 |
| S4 sem S1/S3, sem upstream | Trabalho local | ⛔ |
| Qualquer outro caso | Não candidata | — |

- Branches são conteúdo do usuário: **todas** vão para a quarentena (I9), mesmo as 🟢.
- O motivo cita os sinais encontrados (ex.: "upstream apagado; mudanças já estão em main").
- Com GitHub disponível, o veredito é complementado por T-05.03.

## Critérios de aceite

- [ ] **CA1** Dada uma branch mergeada com merge commit, quando analisada, então o veredito é "Mergeada" 🟢.
- [ ] **CA2** Dada uma branch integrada por squash merge, com o upstream apagado, quando analisada, então o veredito é "Mergeada por conteúdo" 🟡.
- [ ] **CA3** Dada uma branch rebaseada e integrada, quando analisada, então é detectada como mergeada.
- [ ] **CA4** Dada uma branch local nunca enviada com 2 commits que não estão na padrão, quando analisada, então é ⛔ "trabalho local".
- [ ] **CA5** Dada uma branch com upstream apagado e mudanças que não estão na padrão, quando analisada, então é 🔴.
- [ ] **CA6** Dada a branch atual mergeada, quando analisada, então não é candidata.
- [ ] **CA7** Dada uma branch idêntica ao remoto e parada há 60 dias, quando analisada, então é "Cópia de branch remota parada" 🟢.
