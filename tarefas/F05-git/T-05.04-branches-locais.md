# T-05.04 — Limpeza de branches locais

**Feature:** F05 · **Fase:** MVP · **Depende de:** T-05.02, T-05.03, T-09.04

## Regras de negócio

- Cada branch candidata é um **item de organização** (tamanho 0), agrupado por repositório.
- Ação rápida: "limpar todas as mergeadas deste repositório" (só 🟢 e 🟡).
- **Quarentena da branch**: guardar a referência (commit da ponta e configuração de upstream) de forma que os commits **não sejam coletados pelo git** enquanto estiverem na quarentena; depois remover a branch.
- **Restauração**: recria a branch com o mesmo nome, ponta e upstream.
- Se o nome já existir na restauração, o app oferece restaurar com outro nome ou cancelar.
- **Purga**: remove a referência guardada.
- Revalidar antes (I6): se a branch ganhou commits ou passou a ser a atual, o item é pulado.

## Critérios de aceite

- [ ] **CA1** Dada uma branch mergeada mandada para a quarentena, quando o git roda uma coleta de lixo agressiva, então os commits continuam existindo.
- [ ] **CA2** Dada uma branch na quarentena, quando restaurada, então volta com o mesmo nome, commit e upstream.
- [ ] **CA3** Dado que outra branch com o mesmo nome foi criada, quando a restauração é pedida, então o app oferece outro nome.
- [ ] **CA4** Dada uma branch que ganhou um commit depois da análise, quando a limpeza executa, então ela é pulada com o motivo.
- [ ] **CA5** Dado "limpar todas as mergeadas" num repositório com 5 🟢, 2 🟡 e 1 🔴, quando executado, então só as 7 primeiras são selecionadas.
