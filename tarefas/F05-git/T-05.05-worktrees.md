# T-05.05 — Worktrees

**Feature:** F05 · **Fase:** MVP · **Depende de:** T-05.02, T-05.03, T-09.04

## Contexto

Agentes de IA criam uma worktree por tarefa. Cada uma ocupa espaço (muitas vezes com dependências e builds próprios) e fica esquecida depois do merge.

## Regras de negócio

| Situação | Veredito | Risco | Destino |
|---|---|---|---|
| Worktree registrada cuja pasta não existe mais | Metadado órfão | 🟢 (organização) | Remover o registro (não há conteúdo) |
| Pasta com alterações pendentes (incluindo arquivos novos não ignorados) | Trabalho não salvo | ⛔ | — |
| Pasta limpa, mas com commits que não estão em nenhum remoto nem na padrão | Trabalho local | ⛔ | — |
| Worktree **travada** pelo usuário (lock do git) | Travada | ⛔ | — |
| Pasta limpa e branch mergeada (T-05.02/T-05.03) | Worktree concluída | 🔴 | Quarentena |
| Pasta limpa, commits já no remoto, sem merge, sem atividade há mais que o limiar | Worktree parada sem merge | 🔴 | Quarentena |

- A worktree principal do repositório nunca é candidata.
- **Tamanho** = pasta inteira; dependências e builds dentro dela são itens contidos (sem dupla contagem).
- **Arquivos ignorados valiosos**: `.env*`, `*.pem`, `*.key`, `*.sqlite`, `*.db` e similares (lista configurável) geram alerta no item ("contém .env").
- **Ação combinada**: limpar a worktree oferece limpar também a branch dela, se mergeada, numa única ação.
- **Quarentena**: mover a pasta inteira (com os ignorados) e guardar os metadados da worktree. **Restauração**: devolve a pasta e registra a worktree de novo.
- Se um editor ou terminal estiver com arquivos abertos na pasta, o item fica ⛔ na revalidação.

## Critérios de aceite

- [ ] **CA1** Dada uma worktree cuja pasta foi apagada à mão, quando analisada, então é "metadado órfão" 🟢.
- [ ] **CA2** Dada uma worktree com um arquivo modificado, quando analisada, então é ⛔.
- [ ] **CA3** Dada uma worktree limpa de branch mergeada por squash, com `.env` e `node_modules`, quando analisada, então é 🔴 com alerta de `.env` e o `node_modules` aparece como item contido.
- [ ] **CA4** Dada essa worktree na quarentena, quando restaurada, então a pasta volta com o `.env` e o git reconhece a worktree.
- [ ] **CA5** Dada uma worktree travada, quando analisada, então é ⛔ "travada".
- [ ] **CA6** Dada a limpeza combinada de worktree e branch, quando executada, então as duas vão para a quarentena e podem ser restauradas juntas.
