# T-05.06 — Stashes antigos

**Feature:** F05 · **Fase:** MVP · **Depende de:** T-05.01, T-09.04

## Regras de negócio

- Candidato: stash criado há mais tempo que o limiar "idade de stash antigo" (padrão: 30 dias).
- Sempre 🔴, conteúdo do usuário, item de organização.
- O motivo traz: mensagem do stash, branch de origem, data e a lista de arquivos alterados.
- **Quarentena**: guardar o stash de forma restaurável (referência preservada + patch exportado) e removê-lo da lista de stashes.
- **Restauração**: o stash volta para a lista com a mensagem original.
- Stashes mais novos que o limiar não aparecem.

## Critérios de aceite

- [ ] **CA1** Dado um stash de 45 dias, quando analisado, então é 🔴 com mensagem e arquivos no motivo.
- [ ] **CA2** Dado um stash de 5 dias, quando analisado, então não aparece.
- [ ] **CA3** Dado um stash na quarentena, quando restaurado, então volta à lista com a mensagem original e aplica as mesmas mudanças.
