# T-06.01 — Worktrees e workspaces de agentes

**Feature:** F06 · **Fase:** MVP · **Depende de:** T-05.05

## Regras de negócio

- Catálogo configurável de locais onde agentes criam espaços de trabalho. Inicial: Claude Code (`<repo>\.claude\worktrees\*`). Outros agentes (Cursor, Codex, Conductor...) entram no catálogo à medida que os caminhos forem confirmados.
- Worktrees git nesses locais são avaliadas **com as regras de T-05.05** e ganham o rótulo do agente de origem.
- **Pasta solta de agente**: pasta num local de agente que **não** é worktree registrada → 🔴, conteúdo do usuário, quarentena, com o motivo "pasta de agente sem worktree associada".
- O app oferece uma visão "por agente": total ocupado e quantidade de worktrees por agente.

## Critérios de aceite

- [ ] **CA1** Dada uma worktree em `.claude\worktrees\tarefa-x` com branch mergeada, quando analisada, então aparece com o rótulo "Claude Code" e o veredito de T-05.05.
- [ ] **CA2** Dada uma pasta em `.claude\worktrees` que não é worktree registrada, quando analisada, então é 🔴 "pasta solta de agente".
- [ ] **CA3** Dado um local de agente novo adicionado ao catálogo, quando a análise roda, então as worktrees dele aparecem sem mudança de código.
- [ ] **CA4** Dadas 3 worktrees de Claude Code e 2 de outro agente, quando a visão por agente é aberta, então mostra os totais por agente.
