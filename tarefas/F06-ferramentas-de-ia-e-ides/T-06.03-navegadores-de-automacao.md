# T-06.03 — Navegadores de automação

**Feature:** F06 · **Fase:** MVP · **Depende de:** T-02.03

## Contexto

Cada versão do Playwright baixa sua própria versão de Chromium, Firefox e WebKit. Na máquina do usuário são 2,5 GB.

## Regras de negócio

- Fontes: Playwright, Puppeteer e Cypress (caminhos no catálogo).
- Um item por versão de navegador (ex.: `chromium-1140`).
- **Versão referenciada**: exigida por alguma instalação de Playwright/Puppeteer/Cypress encontrada nos projetos.
- Versão não referenciada → 🟡, recriável ("reinstalar com o comando de install da ferramenta").
- Se nenhum projeto tem a ferramenta instalada (por exemplo, `node_modules` apagado), o motivo diz "nenhum projeto instalado usa esta versão". Continua 🟡.
- Versão em uso (processo de navegador rodando a partir da pasta) → ⛔.

## Critérios de aceite

- [ ] **CA1** Dadas as pastas `chromium-1100` e `chromium-1140` e um único projeto que exige 1140, quando analisado, então só a 1100 é candidata.
- [ ] **CA2** Dado um navegador rodando a partir da pasta, quando analisado, então é ⛔.
- [ ] **CA3** Dada uma versão candidata, então o item mostra o comando de reinstalação.
