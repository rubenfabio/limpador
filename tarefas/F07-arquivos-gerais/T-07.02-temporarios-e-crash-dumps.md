# T-07.02 — Temporários e crash dumps

**Feature:** F07 · **Fase:** MVP · **Depende de:** T-01.04

## Regras de negócio

| Item | Regra | Risco |
|---|---|---|
| Temp do usuário (`%TEMP%`) | Entradas sem modificação há mais que o limiar (padrão: 7 dias) | 🟢 |
| Crash dumps do usuário | Arquivos `.dmp` com mais de 7 dias | 🟢 |
| Relatórios de erro arquivados do Windows (do usuário) | Com mais de 7 dias | 🟢 |

- Um item agregado por tipo (ex.: "Temporários: 700 MB").
- Arquivos **em uso** são pulados individualmente na limpeza; o item termina como "parcialmente limpo", com a contagem dos pulados. Isso não é erro.
- Locais que exigem administrador (temp do sistema) ficam fora do escopo.
- Elegíveis para automação.

## Critérios de aceite

- [ ] **CA1** Dados 300 arquivos em Temp, 50 deles modificados ontem, quando analisados, então só os 250 antigos contam.
- [ ] **CA2** Dado um arquivo antigo em uso, quando a limpeza roda, então ele é pulado e o item termina "parcialmente limpo".
- [ ] **CA3** Dados crash dumps de 30 dias, quando analisados, então são 🟢 e elegíveis para automação.
