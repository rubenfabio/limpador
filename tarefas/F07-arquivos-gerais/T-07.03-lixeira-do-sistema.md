# T-07.03 — Lixeira do sistema

**Feature:** F07 · **Fase:** MVP · **Depende de:** T-01.04

## Regras de negócio

- O app mede o tamanho e a quantidade de itens na lixeira de cada unidade.
- O item é 🟢, mas **esvaziar é irreversível**, então:
  - **nunca** é automático;
  - **nunca** pode ser pedido por agente (F12);
  - exige confirmação própria ("isto apaga permanentemente N itens").
- Se a lixeira estiver vazia, o item não aparece.

## Critérios de aceite

- [ ] **CA1** Dada uma lixeira com 1,5 GB, quando analisada, então aparece com tamanho e quantidade.
- [ ] **CA2** Dada a limpeza automática ligada, quando roda, então a lixeira não é esvaziada.
- [ ] **CA3** Dado o pedido de esvaziar, quando o usuário confirma, então a lixeira fica vazia e a ação vai para o log.
