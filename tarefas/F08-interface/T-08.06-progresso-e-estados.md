# T-08.06 — Progresso da análise e estados da interface

**Feature:** F08 · **Fase:** MVP · **Depende de:** T-01.05

## Regras de negócio

- Durante a análise: progresso geral e lista de coletores com o estado de cada um (aguardando · analisando · concluído · erro · indisponível · cancelado · tempo esgotado).
- Botão **Cancelar** sempre visível durante a análise.
- O ranking é atualizado à medida que cada coletor termina.
- A interface continua responsiva durante a análise e a limpeza.

**Estados especiais**

| Estado | O que mostrar |
|---|---|
| Nenhuma pasta raiz | Convite para configurar |
| Nunca analisado | Convite para analisar |
| Nada a limpar | "Tudo limpo", com a data da análise |
| Coletor com erro | Mensagem legível e ação sugerida; detalhes técnicos recolhidos |
| Resultado parcial | Aviso de que um coletor estourou o tempo |

## Critérios de aceite

- [x] **CA1** Dada uma análise em andamento, quando um coletor termina, então seus itens aparecem sem esperar os demais.
- [x] **CA2** Dado o clique em cancelar, quando processado, então a interface volta ao resultado anterior.
- [x] **CA3** Dado um coletor com erro, quando a análise termina, então a mensagem é legível e os detalhes técnicos ficam recolhidos.
- [x] **CA4** Dada uma análise sem nenhum item, quando concluída, então aparece "Tudo limpo".
