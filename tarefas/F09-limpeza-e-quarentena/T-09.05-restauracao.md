# T-09.05 — Restauração da quarentena

**Feature:** F09 · **Fase:** MVP · **Depende de:** T-09.04

## Regras de negócio

- Tela da quarentena: lista com busca, filtro por tipo e ordenação por data de expiração. Cada linha mostra o item, o tamanho, a data de entrada, "expira em N dias" e a origem.
- **Restaurar** devolve o item ao local e ao estado originais e o remove da quarentena.
- **Conflito** (o caminho, a branch ou o volume já existe): o app oferece restaurar com outro nome ou cancelar. **Nunca sobrescreve.**
- **Destino original inexistente** (ex.: o repositório da branch foi apagado): o app oferece exportar o conteúdo para uma pasta escolhida pelo usuário (por exemplo, a branch como pacote git ou patch).
- Restaurações em lote são permitidas; cada item é independente.
- Toda restauração vai para o log.

## Critérios de aceite

- [ ] **CA1** Dada uma pasta na quarentena, quando restaurada, então volta ao caminho original idêntica e sai da lista.
- [ ] **CA2** Dado que o caminho original foi recriado, quando a restauração é pedida, então o app oferece outro nome e não sobrescreve.
- [ ] **CA3** Dada uma branch cujo repositório foi apagado, quando a restauração é pedida, então o app oferece exportar.
- [ ] **CA4** Dada uma restauração em lote com um conflito, quando executada, então os outros itens são restaurados normalmente.
