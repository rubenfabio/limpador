# T-09.06 — Expiração e purga da quarentena

**Feature:** F09 · **Fase:** MVP · **Depende de:** T-09.04

## Regras de negócio

- Uma verificação diária purga (apaga definitivamente) os itens cuja expiração já passou. Se o app estava desligado, a verificação roda na próxima inicialização.
- **Aviso prévio**: um dia antes de purgar itens 🔴, uma notificação avisa "amanhã serão purgados N itens (X GB)", com link para a quarentena.
- **Purgar agora**: o usuário pode purgar itens específicos ou tudo antes do prazo, com confirmação de ação irreversível.
- Mudar o prazo nas preferências vale só para novas entradas.
- Se o disco ficar abaixo do limite de espaço livre, o painel sugere purgar a quarentena antes do prazo.
- Toda purga vai para o log, com o espaço liberado.

## Critérios de aceite

- [ ] **CA1** Dado um item com expiração ontem, quando a verificação diária roda, então ele é apagado definitivamente e a purga vai para o log.
- [ ] **CA2** Dado o app desligado na data de expiração, quando inicia, então purga os itens vencidos.
- [ ] **CA3** Dado um item 🔴 que expira amanhã, quando a verificação roda, então a notificação de aviso aparece.
- [ ] **CA4** Dado o prazo alterado de 14 para 30 dias, quando verificado, então os itens que já estavam na quarentena mantêm a data original.
- [ ] **CA5** Dado "purgar agora", quando confirmado, então os itens somem e o espaço volta ao disco.
