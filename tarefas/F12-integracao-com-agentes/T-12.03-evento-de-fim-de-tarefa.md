# T-12.03 — Evento de fim de tarefa do agente

**Feature:** F12 · **Fase:** 2 · **Depende de:** T-12.02

## Contexto

É aqui que o produto ataca a causa: quando o agente termina, o Limpador já sabe o que ficou para trás.

## Regras de negócio

- Um agente (por hook ou por chamada) avisa "a tarefa terminou" informando a worktree e/ou a branch.
- O Limpador avalia esses recursos com as regras de F05:
  - **mergeada e limpa** → cria um pedido de aprovação "limpar worktree + branch da tarefa X";
  - **ainda não mergeada** → registra para reavaliar nas próximas análises e cria o pedido quando o merge for detectado;
  - **com trabalho não salvo** → não faz nada e registra o motivo.
- Nunca limpa sozinho: worktree e branch são conteúdo do usuário (I9).
- Integração inicial pronta para o Claude Code; o contrato do evento é documentado para outros agentes.

## Critérios de aceite

- [ ] **CA1** Dado o evento de uma worktree mergeada e limpa, quando recebido, então aparece um pedido de aprovação no app.
- [ ] **CA2** Dado o evento de uma worktree ainda não mergeada, quando o PR for mergeado e a análise seguinte rodar, então o pedido é criado.
- [ ] **CA3** Dado o evento de uma worktree com alterações pendentes, quando recebido, então nenhum pedido é criado e o motivo vai para o log.
